# 우물 대사 (임시 초안)

> 상태: **임시.** 톤 기준을 잡기 위한 초안이다. 고칠 줄은 지우거나 고쳐 쓰면 된다.
> 나중에 CONTENT(JSON)로 옮긴다. 대사마다 ID를 붙여 둔 이유다. 우물의 성격은 서버마다 바꿀 수 있다.

## 우물의 성격

- 다정하고 들뜬 존댓말. 누가 올라오면 반가워서 어쩔 줄 모른다.
- **중요한 건 모른다.** 왜 당신이 올라오는지, 그녀가 누구인지, 세상이 어떻게 생겼는지 모른다. 모르는 걸 부끄러워하지도 않는다.
- 설명하지 않는다. 세계관은 대사가 아니라 게임 규칙으로 보여 준다.
- "그녀가 빚은 거대한 무언가"는 절대 언급하지 않는다.

## 표기

- `{name}` 플레이어 이름
- `[선택지]` 플레이어가 고르는 답
- `(연출)` 화면·소리 지시
- 같은 ID에 `a`, `b`가 붙은 줄은 무작위로 하나만 나온다.

## 1. 깨어남

(화면이 물속처럼 일렁이다가 천천히 맑아진다. 물방울 소리.)

| ID | 대사 |
|---|---|
| wake.01 | 어! 어어! 올라오셨네요! |
| wake.02 | 잠깐만요, 아직 물기가 덜 빠졌어요. 천천히, 천천히. |
| wake.03 | 괜찮아요? 어디 아픈 데는요? …아, 아픈 건 아마 없을 거예요. 다들 그렇더라고요. |
| wake.04 | 저는 우물이에요. 가끔 당신 같은 분들이 제 안에서 올라와요. |
| wake.05 | 왜 올라오시는지는… 저도 잘은 몰라요. 그냥 반가워요! |

[선택지]
- `wake.ask.where` 여기가 어디예요?
  - wake.where.01 — 여기요? 음… 우물 옆이요! 그 이상은 저도 잘 몰라요. 저는 여기서 움직여 본 적이 없거든요.
- `wake.ask.who` 나는 누구예요?
  - wake.who.01 — 그건 이제부터 정하시면 돼요! 일단 얼굴부터 볼까요?

## 3. 이름 짓기

| ID | 대사 |
|---|---|
| name.01 | 이름은 뭐라고 불러 드릴까요? |
| name.02 | 아, 저요? 저는 그냥… 우물이에요. 다들 그렇게 불러요. |
| name.ok | {name}! 좋은 이름이에요. 몇 번 불러 볼게요. {name}, {name}… 네, 외웠어요! |

### 이름이 안 될 때

서버가 이름을 확정하고, 안 되는 이유에 따라 우물이 다시 묻는다.

| ID | 상황 | 대사 |
|---|---|---|
| name.taken | 이미 누가 쓰는 이름 | 어, 그 이름은 벌써 누가 쓰고 있어요! 저도 헷갈릴 것 같아요. 다른 걸로 해 주실래요? |
| name.empty | 빈 이름 | 음… 아무것도 안 들렸어요. 한 번만 더 말해 주세요! |
| name.too_long | 12자 넘음 | 우와, 길다! 제가 다 못 외울 것 같아요. 조금만 줄여 주실래요? |
| name.bad | 쓸 수 없는 문자·말 | 그건… 왠지 부르기 어려운 이름이에요. 다른 걸로 해 볼까요? |
